它解决的是「记过，但想不起来」

不是把文本塞进向量库就完事。写入、检索、注入、生命周期四层互相约束。

多路召回

BM25 词法 + bge-m3 向量 + PPR 图增强多跳 + PRF 查询扩展，RRF 融合；字面搜不到也能靠共享实体桥接，结果标「联想」。

有强度、会衰减

FSRS 式排序：相关度 × 保持度 × 效用 × 重要度 × 退役惩罚。长期不用的记忆休眠，软删 30 天内可恢复。

自动整理

近重复自动合并（0.92），冲突自动打标并裁决（0.75 起），周期巩固把同簇记忆压成一条带证据的产物。

上下文友好

500 token 动态预算 + TextRank 抽取式摘要 + 注入前冲突消解，长记忆不靠截断，只抽原文不编造。

可解释

每次注入的触发原因、候选、过滤、省略、预算都能在「审计」页看到；工具输出带来源标记。

数据不出机

JSONL + 本地向量缓存，可读可 diff 可迁移；凭据命中拒绝写入；不配向量后端时零网络请求。

七个面板页，全部本地

服务 / 记录 / 知识树 / 关系分析 / 规则代码 / 设置 / 审计。

四层结构

每一层都能单独关掉或调参，面板与配置文件同一套开关。

写入层   scope / kind / importance / tags / TTL / 密钥脱敏
   ↓
检索层   BM25 + bge-m3 向量 + PPR 图增强 + PRF → RRF 融合 → cross-encoder 重排
   ↓
上下文层 动态 token 预算 → TextRank 摘要 → 冲突消解 → 注入
   ↓
生命周期 FSRS 强度 → 语义合并 → 冲突裁决 → 周期巩固 → 休眠 / 软删

30 秒安装

要求 DSH + Node ≥ 22.13。装完重启一次 dsh web。

dsh plugin --profile web add "github:HANPU5838/dsh-memory#main"
你想要的怎么做
零配置先跑起来装完即用，没有向量后端时自动退化为纯词法检索，不联网
开语义检索面板「服务 → 向量服务」一键安装（Termux：pkg install llama-cpp + 自动下载 bge-m3）
只想用词法不装后端即可；检索仍走 BM25 + PRF + 图增强
换机器 / 备份复制整个 ~/.dsh-memory，或在面板导出
